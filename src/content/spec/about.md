## 为什么会有这个小站

很多问题当时解决了，过一阵又会忘记，于是有了这里。它是我的公开笔记本，主要记录系统安装、软件配置、网络服务，以及那些花了时间才弄明白的小问题。

文章首先写给未来的自己：保留过程、说清原因、给出能够复现的答案。如果恰好也帮路过的你少走了一点弯路，那就更好了。

本站使用 [Astro](https://astro.build/) 构建，基于 [Fuwari](https://github.com/saicaca/fuwari) 主题，并通过 GitHub Pages 发布。除特别说明外，原创内容采用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans) 许可。

博客没有固定更新频率。遇到值得记录的事，想清楚了就写；比起追求数量，我更希望每篇内容以后还能派上用场。
