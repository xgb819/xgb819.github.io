# 前言

公司内部需要共享一批资料，以往主要通过网盘进行流转，但在多人协作、文件同步等方面存在一定不便。Windows 自带的文件共享功能无法直接满足跨网络访问的需求。

通过 Tailscale 建立虚拟局域网，结合 Windows 文件共享，即可实现不同网络环境下的设备互相访问，搭建一个简单、高效的内部资料共享方案。

# 部署流程

## Tailscale 安装与部署

两台电脑安装 [Tailscale](https://tailscale.com/download)。

建议管理者使用自己的账号，其他用户使用独立账号加入，避免共享账号密码。

进入 [Admin Console](https://login.tailscale.com/admin) → [Users](https://console.tailscale.com/admin/users)，点击 Invite external users，复制邀请链接，其他用户接受邀请后，管理者需要在后台同意申请，设备会自动加入同一个 Tailnet（接受邀请后，其他用户需要选择管理者邮箱，否则会进入自己创建的 Tailnet）。

## 设置 Windows 文件共享

选择需要共享的文件夹，右键属性 → 共享 → 高级共享，开启共享此文件夹。

如果其他用户需要上传文件，需要在属性 → 共享 → 高级共享 → 权限，开启 Everyone 的更改与读取权限。同时检查属性 → 安全 → 编辑，确保 Everyone 拥有修改与写入权限，否则只能查看，不能上传。

其他用户此电脑右键 → 映射网络驱动器，文件夹填属性 → 共享 → 网络文件和文件夹共享中的「网络路径」，即可访问共享文件，如果想以后不用输入，可以勾选登录时重新连接（默认勾选）

# 电脑和硬盘要求

由于共享文件实际存储在你的电脑上，必须保持电脑开机和Tailscale 在线，建议开启 Tailscale 开机启动（默认开启）和工作时间关闭自动睡眠。

远程访问速度主要取决于电脑的上传带宽，多人同时访问会共享上传速度，如果有大量人员同时访问、高频大文件传输等需求，建议使用 NAS 实现跨网络文件共享。
